# Skystore

Skystore — это простой веб-сервис для демонстрации и продажи плагинов, примеров кода и других цифровых продуктов. Приложение построено на Django с использованием Bootstrap для фронтенда.

---

## Функционал

- Главная страница с каталогом товаров и описанием сервиса
- Страница контактов с формой обратной связи
- Обработка POST-запросов и отображение страницы благодарности после отправки формы
- Единый стиль страниц с использованием Bootstrap
- Статические файлы: CSS и JS подключены для стилизации и интерактивности

---

## Установка и запуск

1. Создайте виртуальное окружение и установите зависимости:

python -m venv .venv
source .venv/bin/activate   # Linux / Mac
.venv\Scripts\activate      # Windows
pip install -r requirements.txt

2. Запустите сервер:

python manage.py runserver

Откройте в браузере: http://127.0.0.1:8000/

---

## Использование

- На странице контактов заполните форму и отправьте сообщение  
- Сервер выведет сообщение в логах (для тестирования)  
- Пользователь увидит страницу благодарности с информацией о доставке сообщения
